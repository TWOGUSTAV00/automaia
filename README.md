# Automaia

Site estatico de ferramentas online gratuitas, construido com Vite, HTML, CSS e JavaScript puro.

## Recursos

- 10 ferramentas client-side para imagem, texto, QR Code, JSON, senha e links.
- Painel admin local em `admin.html`.
- Web Crypto API para senha admin, sessao local e backup criptografado.
- Headers de seguranca para Cloudflare Pages.
- Deploy automatico para GitHub Pages via GitHub Actions.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
